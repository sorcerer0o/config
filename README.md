# Oh My Posh Config

Custom single-line theme for PowerShell (Windows Terminal).

## Usage

```powershell
oh-my-posh init pwsh --config "$env:USERPROFILE\.oh-my-posh\custom.omp.json" | Invoke-Expression
```

Requires a Nerd Font (e.g. JetBrainsMono Nerd Font) for icons.

## Install Instructions

 > Install requires Neovim 0.9+. Always review the code before installing a configuration.

Clone the repository and install the plugins:

```sh
git clone git@github.com:sorcerer0o/config ~/.config/sorcerer0o/config
```

Open Neovim with this config:

```sh
NVIM_APPNAME=sorcerer0o/config/ nvim
```
